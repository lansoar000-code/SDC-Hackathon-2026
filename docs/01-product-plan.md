# 项目效果与当前进度
目标：帮助中小餐厅根据历史销量与可提前知道的条件，估计下一天各菜品需求，并提供备餐参考。

| 使用步骤 | 当前实现 |
|---|---|
| 准备历史销量 | 空 CSV 模板；支持 CSV/XLSX |
| 导入、校验 | 逐行错误、重复拒绝、整批事务 |
| 设置预测条件 | 日期、天气、考试周、活动、模式和备餐余量 |
| 生成结果 | 各菜预测销量、备餐量、合计、来源和说明 |
| 训练和比较 | 按日期验证 Ridge 与历史基线，逐菜择优 |
| 保存预测 | 条件、数据截止、版本、明细快照 |
| 查询与导出 | 历史分页、详情、CSV |
| 实际反馈 | 新增销量，对齐预测，显示图表与指标 |

当前是本地单餐厅版本；尚无独立真实数据效果证明。基线只依据销量历史；模拟模式明确区分。
未来可扩展账号、多餐厅、自动天气、纠错编辑和库存联动。
