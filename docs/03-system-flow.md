# 已实现的数据流
```text
run.py → FastAPI 应用
用户页面 → /api/* 路由 → 服务层 → SQLite
                              ↓
                       forecasting 预测模块
                              ↓
                      结果快照保存 → 页面展示
```

导入：文件 → 逐行校验 → 数据库冲突校验 → 整批写入。
训练：历史数据快照 → 按时间训练/验证 → 模型与基线比较 → JSON 参数文件。
预测：目标日之前的历史 → 校验模型数据指纹 → 模型或基线 → 备餐余量计算 → 保存记录。
反馈：实际销量 → 日期/菜品对齐 → 标注补做历史预测 → 图表和误差指标。

前端与 API 在同一服务，默认 http://127.0.0.1:8000。SQLite 和模型目录不会通过静态文件服务公开。
具体函数调用顺序见 [代码阅读指南](09-code-reading.md)。
